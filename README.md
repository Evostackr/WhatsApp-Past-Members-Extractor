# WhatsApp Past Members Extractor

[![Status](https://img.shields.io/badge/status-active-success.svg)]()
[![Type](https://img.shields.io/badge/type-Browser%20Extension%20/%20Tool-blue.svg)]()
[![License](https://img.shields.io/badge/license-MIT-purple.svg)]()

> A browser automation script/extension to extract and export contact numbers of past and existing members from WhatsApp Web groups.

---

## 🌟 Key Features

- **One-click group metadata and 'Past Members' list extraction**
- **Phone number formatting and country code standardization**
- **Export contacts to CSV, VCF (vCard), or JSON formats**
- **100% client-side execution with zero external data transmission**

---

## 🛠️ Tech Stack & Technologies

- **Project Type:** Browser Extension / Tool
- **Technologies Used:** JavaScript, DOM Parser, WhatsApp Web Bridge
